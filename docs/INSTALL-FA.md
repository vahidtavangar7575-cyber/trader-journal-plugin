# نصب نسخه فارسی Trader Journal

این Fork برای استفاده فارسی و راست‌چین در Obsidian آماده شده است و شامل Wizard تصمیم‌گیری ستاپ‌های خان، ژورنال Live/Backtest، پلن معاملاتی، داشبورد، تقویم و ثبت ساختاریافته Metadata است.

## روش پیشنهادی: فایل ZIP آماده

1. به صفحه **Releases** همین مخزن بروید و آخرین نسخه را باز کنید.
2. فایل `trader-journal-<version>.zip` را دانلود کنید.
3. فایل ZIP را Extract کنید. داخل آن پوشه‌ای به نام `trader-journal` وجود دارد.
4. پوشه `trader-journal` را داخل مسیر زیر در Vault قرار دهید:

```text
<Vault>/.obsidian/plugins/
```

در پایان باید این فایل‌ها وجود داشته باشند:

```text
<Vault>/.obsidian/plugins/trader-journal/manifest.json
<Vault>/.obsidian/plugins/trader-journal/main.js
<Vault>/.obsidian/plugins/trader-journal/styles.css
```

5. Obsidian را Reload کنید.
6. به **Settings → Community plugins** بروید و **Trader Journal** را فعال کنید.

## شروع کار

پس از فعال‌سازی افزونه:

- از Ribbon روی آیکن Wizard خان بزنید، یا
- Command Palette را باز کنید و `Trader Journal` را جست‌وجو کنید.

برای مسیر پیشنهادی استفاده:

1. Wizard خان را باز کنید.
2. به سؤال‌های مرحله‌ای پاسخ دهید.
3. در صورت رسیدن به یک Setup معتبر، نتیجه و ریسک پیشنهادی نمایش داده می‌شود.
4. نتیجه را مستقیماً به فرم معامله Live یا Backtest منتقل کنید.
5. بعداً آمار و Review را از Dashboard بررسی کنید.

## نکات مهم درباره داده‌ها

- زبان پیش‌فرض این Fork فارسی است.
- رابط فارسی RTL است؛ Symbol، قیمت، تاریخ، عدد و داده‌های فنی LTR باقی می‌مانند.
- کلیدهای داخلی JSON و Frontmatter ترجمه نمی‌شوند تا سازگاری تاریخی داده‌ها حفظ شود.
- داده‌های اصلی ژورنال در Vault شما ذخیره می‌شوند.
- تقویم اقتصادی و تصاویر Remote تنها در صورت فعال‌سازی تنظیمات مربوطه به شبکه درخواست می‌زنند.

## حداقل نسخه

- Obsidian: `1.6.6` یا جدیدتر.

## ارتقا نسخه

برای ارتقا، فایل‌های نسخه جدید را روی همین پوشه جایگزین کنید. فایل‌های داده، ژورنال‌ها، پلن‌ها و ستاپ‌های شما داخل Vault باقی می‌مانند و نباید پوشه‌های داده را حذف کنید.

## رفع اشکال سریع

اگر افزونه دیده نمی‌شود:

- مطمئن شوید نام پوشه دقیقاً `trader-journal` است.
- مطمئن شوید `manifest.json` مستقیماً داخل همان پوشه است و یک پوشه اضافی بین آن‌ها وجود ندارد.
- Obsidian را Reload کنید.
- در **Settings → Community plugins** افزونه را دوباره فعال کنید.
