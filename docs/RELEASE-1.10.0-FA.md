# Trader Journal 1.10.0 — محاسبه‌گر حجم حرفه‌ای

این نسخه موتور محاسبه حجم معامله را برای نمادهای اصلی مورد استفاده اضافه می‌کند:

- EURUSD
- XAUUSD / GOLD
- US30 / Dow Jones
- DAX40 / GER40
- NAS100 / Nasdaq 100
- USOIL / WTI
- BTCUSD

## جریان جدید

حساب/سرمایه + درصد ریسک + Symbol + Entry + Stop Loss → محاسبه خودکار فاصله استاپ، ارزش pip/point/tick، زیان یک لات تا استاپ و حجم پیشنهادی.

حجم همیشه بر اساس `volumeStep` رو به پایین گرد می‌شود تا گردکردن باعث عبور از ریسک تعریف‌شده نشود.

## نرخ تبدیل

اگر ارز Quote نماد با ارز حساب متفاوت باشد (برای مثال DAX40 روی حساب USD)، افزونه نرخ تبدیل آنلاین را از Frankfurter دریافت می‌کند. این نرخ مرجع روزانه است، نه تیک لحظه‌ای بازار؛ تاریخ نرخ در UI نمایش داده می‌شود و اگر نرخ معتبر دریافت نشود حجم نهایی ساخته نمی‌شود.

## نکته مهم CFD

Contract Size شاخص‌ها، طلا، نفت و بیت‌کوین می‌تواند بین بروکرها متفاوت باشد. افزونه یک پروفایل مرجع آماده دارد اما Contract Size در خود محاسبه‌گر قابل مشاهده و تغییر است؛ برای دقت صددرصد، مشخصات Symbol بروکر را یک‌بار تطبیق بده.

## تست‌های عددی

محاسبات EURUSD، XAUUSD، DAX40 و aliasهای اصلی با تست خودکار پوشش داده شده‌اند.
