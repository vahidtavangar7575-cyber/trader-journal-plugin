# نصب دستی 1.13.0

1. Obsidian را کامل ببند.
2. ZIP نسخه 1.13.0 را باز کن.
3. در پوشه `.obsidian/plugins/trader-journal/` فقط این سه فایل را جایگزین کن:
   - `main.js`
   - `manifest.json`
   - `styles.css`
4. فایل `data.json` را حذف نکن؛ حساب‌ها و تنظیمات شخصی در آن باقی می‌مانند.
5. Obsidian را باز کن و Trader Journal را یک‌بار خاموش/روشن کن.
6. در Manifest باید نسخه `1.13.0` دیده شود.
