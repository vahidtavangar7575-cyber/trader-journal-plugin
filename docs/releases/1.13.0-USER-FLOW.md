# جریان کار نهایی 1.13.0

`تعهد روزانه → صفحه اصلی → شروع Presentation از صفحه 1 → سؤال/دستور صفحه → راهنمای عملی همان مرحله → پاسخ → Result → بلیت معامله → حساب/ریسک/حجم/تصاویر → ثبت OPEN → بستن همان رکورد → گزارش فارسی + Review`
