# Trading Cockpit فارسی — UX، تعهد، ریسک و ثبت معامله

این سند منطق نسخه جدید رابط Trader Journal را توضیح می‌دهد.

## اصل طراحی

**پیچیدگی در موتور، سادگی در صفحه.**

کاربر نباید برای استفاده روزانه مجبور باشد نمودار ۵۸ صفحه‌ای Presentation یا تمام اصطلاحات دوره را حفظ کند. سیستم باید هر بار فقط تصمیم بعدی مرتبط را نشان دهد.

## آیین شروع جلسه

Wizard قبل از ورود به نمودار، متن تعهد را نمایش می‌دهد و کاربر باید آن را خودش تایپ کند. Paste غیرفعال است. هدف این مرحله «تضمین سود» یا تغییر جادویی باور نیست؛ هدف ایجاد اصطکاک رفتاری، کاهش ورود عجولانه و یادآوری کنترل‌پذیرهاست: کیفیت مشاهده، صبر، ریسک و اجرای پلن.

## صفحه خانه

دو مسیر اصلی دارد:

1. **تشخیص هوشمند از وضعیت فعلی بازار** — مسیر پیشنهادی استفاده روزانه.
2. **مرور یا شروع مستقیم یکی از ۶ ستاپ** — برای آموزش، بک‌تست و مرور یک Setup مشخص.

## Router موقعیت بازار

قبل از Rule Engine از کاربر پرسیده می‌شود وقتی پای چارت نشست قیمت کجا بوده است:

- در مسیر POI
- داخل/روی POI
- بعد از واکنش POI
- وسط حرکت/ستاپ
- از قبل داخل معامله

این Router جزو Ruleهای Khan نیست؛ یک لایه UX اجرایی است. هدف آن جلوگیری از این فرض اشتباه است که کاربر همیشه دقیقاً در آغاز Setup پای چارت می‌نشیند.

اگر قیمت هنوز در مسیر POI باشد، سیستم وارد «حالت انتظار حرفه‌ای» می‌شود: ثبت سناریو، Screenshot تایم بالاتر و ممنوع‌کردن ورود زودهنگام تا Trigger.

اگر کاربر دیر رسیده باشد، سیستم هشدار ضد Chase نشان می‌دهد: حرکت از دست‌رفته Setup جدید ایجاد نمی‌کند.

## شش ستاپ

شش Setup اصلی Presentation حفظ شده‌اند:

- Setup 1: POI → M1 → IDM/CHOCH → SCOB
- Setup 2: Shadow/Imbalance → HTF POI → M1
- Setup 3: M15 Shadow → M1 Structure → SCOB
- Setup 4: Fake CHOCH → Pullback Break → Reverse IDM
- Setup 5: PDH/PDL → M15 → SCOB → Daily Direction
- Setup 6: Major Pullback POI → HTF IDM → OF → SCOB

Entry Moduleهای دوره مثل CHOCH، Flip، SCM و SCOB در نسخه فعلی به‌عنوان لایه‌های اجرا/تأیید در نظر گرفته می‌شوند، نه Setup شماره ۷. اگر بعداً داده و منبع نشان دهد یک Setup مستقل لازم است، با Rule ID مستقل اضافه می‌شود.

## ریسک

Wizard مقدار ریسک شاخه Presentation را نمایش می‌دهد. کاربر می‌تواند یک سقف شخصی پایین‌تر وارد کند. ریسک نهایی برابر مقدار کمتر بین «ریسک منبع» و «سقف شخصی» است.

اگر Equity وارد شود، مبلغ ریسک محاسبه می‌شود:

`Risk amount = Equity × Risk % / 100`

Lot/Contract/Unit به‌صورت جداگانه ثبت می‌شود. محاسبه خودکار Position Size برای Forex تا زمانی که Contract specification، account currency و pip value به‌صورت قابل اتکا مدل نشده‌اند عمداً انجام نمی‌شود.

## روان‌شناسی و باورسازی

سیستم به‌جای تلقین نتیجه‌محور روی رفتارهای قابل‌اندازه‌گیری کار می‌کند:

- تعهد تایپی قبل از شروع
- ثبت حالت ذهنی قبل از ورود
- ثبت شدت میل به تعقیب قیمت از ۰ تا ۱۰
- هشدار هنگام Chase بالا
- Review بعد از معامله: Context، Timing، Plan adherence، اشتباهات، درس و اقدام بعدی

هدف این است که «برد = ارزشمندی» و «باخت = شکست شخصی» از چرخه تصمیم حذف شود و کیفیت فرایند به متغیر اصلی تبدیل شود.

## محدودیت مهم

قواعد مدیریت سرمایه شخصی که خارج از این Repository یا فایل‌های فعلی تعریف شده‌اند نباید حدس زده شوند. تا زمانی که آن قواعد دقیق وارد سیستم نشوند، لایه Risk فقط از ریسک شاخه Presentation و سقف شخصی واردشده توسط کاربر استفاده می‌کند.
