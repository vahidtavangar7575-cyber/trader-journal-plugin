# Trader Journal 1.14.0 — UX حرفه‌ای، ۶ ستاپ کامل و حجم بروکر-محور

این نسخه روی حفظ ظاهر و بخش‌های تأییدشده تمرکز دارد و فقط بخش‌هایی را که در استفاده واقعی مشکل داشتند ارتقا می‌دهد.

## مهم‌ترین تغییرات

- هر **۶ Setup منبع Khan/Presentation** به‌صورت خودکار در ژورنال آماده می‌شوند؛ دیگر فقط ستاپ‌هایی که قبلاً استفاده شده‌اند در داشبورد دیده نمی‌شوند.
- Dashboard صریحاً تفاوت **Setup** با ماژول‌های ورود مثل `SCOB / CHOCH / Flip / SCM / OF / OB` را توضیح می‌دهد.
- مسیر **برخورد به POI → Refinement M1 → IDM/CHOCH → واکنش SCOB به Decisional/Extreme** در توضیح ستاپ‌ها و داشبورد روشن شده است؛ برخورد POI به‌تنهایی Entry نیست.
- تجربه تصاویر به حالت حرفه‌ای بازگشته و برای همه معاملات، نه فقط معاملات ساخته‌شده از Wizard، دو جایگاه اصلی دارد:
  - تصویر 15m / HTF
  - تصویر 1m / LTF
- انتخاب فایل مستقیم از کامپیوتر، Drag & Drop، Preview، تعویض، حذف و بازکردن تصویر.
- تصاویر به‌صورت خودکار در مسیر ساختاریافته `_attachments/<SYMBOL>/<YYYY>/<MM>/<DD>` ذخیره می‌شوند.
- تصاویر تکمیلی/خروج همچنان با Paste یا مسیر/لینک قابل ثبت‌اند.
- موتور محاسبه حجم، **پروفایل اجرایی CFD/Spot** را از **مرجع رسمی Futures** جدا می‌کند تا قرارداد بورس به اشتباه روی حساب بروکر اعمال نشود.
- برای XAUUSD، US30، DAX40/GER40، NAS100، USOIL/WTI، BTCUSD و EURUSD مرجع رسمی قرارداد بازار نمایش داده می‌شود.
- Contract Size بروکر را می‌توان یک‌بار ذخیره کرد و از آن به بعد برای همان نماد خودکار استفاده کرد.
- خروجی حجم معامله بزرگ، واضح و قابل اعمال با یک کلیک است و مثل قبل همیشه رو به پایین گرد می‌شود تا Risk افزایش پیدا نکند.
- خوانایی کارت ستاپ‌های Dashboard و متن‌های بلند بهتر شده است.

## اصل مهم قراردادها

برای حساب‌های Prop/CFD، مشخصات Symbol خود بروکر مرجع اجرای Position Size است. مشخصات رسمی CME/Eurex صرفاً برای تطبیق و آموزش نمایش داده می‌شوند و بدون تأیید کاربر جایگزین قرارداد بروکر نمی‌شوند.

## سازگاری داده

`data.json` و معاملات قبلی حفظ می‌شوند. تنظیم جدید Contract Size بروکر به داده‌های قبلی آسیبی نمی‌زند.
