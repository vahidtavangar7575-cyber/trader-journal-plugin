# راهنمای فارسی Trader Journal

این Fork برای تجربه‌ی فارسی و راست‌چین توسعه داده می‌شود.

## مرحله فعلی
- زبان فارسی به تنظیمات افزونه اضافه شده است.
- فارسی زبان پیش‌فرض این Fork است.
- بخش‌های اصلی رابط کاربری ترجمه شده‌اند.
- رابط افزونه در حالت فارسی RTL می‌شود.
- فیلدهای عددی، قیمت، تاریخ و کد عمداً LTR نگه داشته می‌شوند.
- کلیدهای JSON، Frontmatter و شناسه‌های داخلی ترجمه نشده‌اند تا داده‌های ژورنال خراب نشوند.

## مسیر بعدی
1. تکمیل ترجمه همه رشته‌های رابط.
2. تست RTL در Dashboard، Calendar و Modalها.
3. ساخت Wizard ساده برای Setupهای Khan.
4. افزودن Rule Registry و داده‌های قابل بک‌تست.

اصل طراحی: **پیچیدگی در موتور، سادگی در صفحه.**
